# 二、数组
## 题目
```
给你一个按 非递减顺序 排序的整数数组 nums，返回 每个数字的平方 组成的新数组，要求也按 非递减顺序 排序。
```

示例 1：

输入：nums = [-4,-1,0,3,10]
输出：[0,1,9,16,100]
解释：平方后，数组变为 [16,1,0,9,100]，排序后，数组变为 [0,1,9,16,100]
示例 2：

输入：nums = [-7,-3,2,3,11]
输出：[4,9,9,49,121]

## 讲解思路

### 1.暴力排序
最直观的想法，莫过于：每个数平方之后，排个序，代码如下：
```python
（版本一）暴力排序法
class Solution:
    def sortedSquares(self, nums: List[int]) -> List[int]:
        for i in range(len(nums)):
            nums[i] *= nums[i]  # *=：乘法复合赋值运算符  --->原地修改：直接改变原数组内的元素，不会创建新数组。
        nums.sort()
        return nums
```
```
# 复杂度为：O(n)
for i in range(len(nums)):
    nums[i] *= nums[i]

# 时间复杂度为：O(nlogn)
nums.sort()

这个时间复杂度是 O(n + nlogn)， 可以说是O(nlogn)的时间复杂度，但为了和下面双指针法算法时间复杂度有鲜明对比，我记为 O(n + nlog n)。
```
## 2.双指针法
```
数组其实是有序的， 只不过负数平方之后可能成为最大数了。

那么数组平方的最大值就在数组的两端，不是最左边就是最右边，不可能是中间。

此时可以考虑双指针法了，i指向起始位置，j指向终止位置。

打个比方：
一排人从左到右身高递增，但左边是 “倒立的人”（负数）。算 “身高平方” 的话，最左和最右的人平方最大，越往中间越小。我们从两头开始比，每次挑更高的，从队伍末尾往前排，走一遍就排好了。

```
如动画所示：

代码如下：
```python
（版本二）双指针法
class Solution:
    def sortedSquares(self, nums: List[int]) -> List[int]:
        l, r, i = 0, len(nums)-1, len(nums)-1 
        res = [float('inf')] * len(nums) # 创建一个长度与 `nums` 完全相同的新列表 `res`，列表里的每一个元素都初始化为正无穷大（`inf`）
        while l <= r:# 循环继续的条件是「左指针不超过右指针」。当 `l == r` 时，还剩最后一个中间的元素，也要放进结果里，所以用 `<=`，不能漏掉。
            if nums[l] ** 2 < nums[r] ** 2: # 左右边界进行对比，找出最大值
                res[i] = nums[r] ** 2
                r -= 1 # 右指针往左移动 
            else:
                res[i] = nums[l] ** 2
                l += 1 # 左指针往右移动
            i -= 1 # 存放结果的指针需要往前平移一位
        return res
```
此时的时间复杂度为O(n)，相对于暴力排序的解法O(n + nlog n)还是提升不少的。

其中：
```
- `l`（左指针）：指着数组最开头（下标 0），从左往右走
- `r`（右指针）：指着数组最末尾（下标`len(nums)-1`），从右往左走
- `i`（写入指针）：指着结果数组的**末尾**。因为我们每次找到的都是当前最大的数，所以从后往前填最顺手
- `res`：提前造好一个和原数组一样长的数组，先用无穷大占位置（后面都会被覆盖），用来存最终的平方结果
- `列表 * 整数n` = 将列表内的元素重复 n 次，生成一个全新的列表

```
