# 一、复杂度
# 1. 时间复杂度(数据量翻一倍，你的代码运行时间会翻几倍)
时间复杂度：当输入的数据量n越来越大时，程序运行时间会涨得有多快？
```
它不是算程序具体跑多少毫秒（那和电脑性能、编程语言有关），而是衡量：
当数据量 n 变大时，程序运行时间的增长速度。
说白了就是：数据量翻一倍，你的代码运行时间会翻几倍？我们只关心 “增长趋势”，不关心具体数字，所以用「大 O 表示法」来统一描述。
```
```
计算大 O 的核心规则（抓主要矛盾，忽略细枝末节）：
只看最高次项：比如总次数是 3n² + 2n + 5，n很大时n²才是主导，记为 O(n²)
忽略常数系数：比如 2n 次操作，系数 2 不改变增长趋势，记为 O(n)
只关心和n相关的部分：固定执行 100 次的代码，和数据量无关，记为 O(1)

```


## 1.1 计算步骤
```
找到代码里执行次数最多的部分（一般是循环、递归）
算出这部分执行次数和数据量 n 的关系式
用上面 3 条铁则化简，得到最终的大 O

```
## 1.2 常见等级


### 1. O (1) 常数级
特点：不管数据量 n 多大，执行次数永远固定。

``` python
# 生活类比：按电梯按钮，不管楼里多少人，你只按一次。
def get_first(arr):
    # 不管arr长度是1还是100万，这行只执行1次
    return arr[0]

```
解释：通过索引直接取列表元素，一步到位，是最快的时间复杂度。



### 2. O (logn) 对数级
特点：每次操作都把数据量砍掉一半，增长特别慢。
最典型的是二分查找的核心逻辑：
```python
# 生活类比：猜数字游戏（1-100 里猜数，每次告诉你大了还是小了），每次排除一半答案，100 个数最多猜 7 次。
def binary_search(sorted_arr, target):
    left, right = 0, len(sorted_arr) - 1
    while left <= right:
        mid = (left + right) // 2
        if sorted_arr[mid] == target:
            return mid
        elif sorted_arr[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1

```
解释：每次循环搜索范围缩小一半，n个元素最多找 log₂n 次。大 O 不关心对数底数，统一记为 O(log n)。


### 3. O (n) 线性级
特点：数据量翻几倍，运行时间就翻几倍。
最典型的就是一层 for 循环：
```python
# 生活类比：从头到尾翻一遍通讯录找名字，联系人多一倍，你找的时间多一倍。
def print_all(arr):
    # 列表长度是n，循环就跑n次
    for num in arr:
        print(num)
```
解释：循环次数完全由数组长度决定。哪怕循环里写了 2 行 print，系数 2 会被忽略，依然是O(n)。


### 4. O (n log n) 线性对数阶
特点：n次循环 × 每次logn次操作，是高效排序算法的标配（归并排序、快速排序平均情况）。
```python

def n_logn_demo(n):
    # 外层跑n次
    for i in range(n):
        j = n
        # 内层每次减半，跑logn次
        while j > 0:
            j = j // 2
            print(i, j)
```
解释：总执行次数是 n × logn，所以是O(n log n)。


### 5. O (n²) 平方阶
特点：两层嵌套循环，n 翻 2 倍，时间翻 4 倍，增长速度很快。
典型的双重 for 循环、冒泡排序都在这个级别：

```python
def print_all_pairs(arr):
    n = len(arr)
    for i in range(n):      # 外层n次
        for j in range(n):  # 内层每次也跑n次
            print(arr[i], arr[j])
```
解释：总执行次数是n×n，所以是O(n²)。
哪怕内层从i开始循环（比如冒泡排序），总次数是 n(n-1)/2，去掉系数和低次项，依然是O(n²)。

### 6. O (2ⁿ) 指数阶
特点：爆炸式增长，n=30 就会明显卡顿，属于非常低效的算法。
典型的是未经优化的递归斐波那契：
```python

def fib(n):
    if n <= 1:
        return n
    # 每次调用分裂成2个子调用
    return fib(n-1) + fib(n-2)
```
解释：递归深度每加 1，调用次数翻一倍，总调用次数近似2ⁿ，所以是O(2ⁿ)。



# 2. 空间复杂度(数据量翻一倍，你需要额外多开多少内存空间。)

空间复杂度衡量的是：除了输入数据本身之外，程序额外开辟的内存的增长趋势。
输入的数组本身占的空间不算，只算你为了运行程序额外申请的空间（变量、新数组、递归栈等）。

```
同理，它不是算程序具体占多少 MB 内存，而是衡量：
当数据量 n 变大时，程序额外占用内存的增长速度。
也就是：数据量翻一倍，你需要额外多开多少内存空间。

```

### 1. O (1) 常数空间
特点：额外开的变量数量固定，和n无关。
```python

def sum_arr(arr):
    total = 0  # 只额外开了1个变量
    for num in arr:
        total += num
    return total
```
解释：不管数组多长，只用到一个total变量，空间固定。冒泡排序这种直接在原数组上交换的算法，空间复杂度也是O(1)。

### 2. O (n) 线性空间
特点：额外开辟的空间和n成正比。
示例 1：新建一个长度为 n 的数组
```python

def copy_arr(arr):
    new_arr = []  # 新数组长度和原数组一样是n
    for num in arr:
        new_arr.append(num)
    return new_arr
```
示例 2：递归调用（递归栈占用空间）
```python

def factorial(n):
    if n <= 1:
        return 1
    # 递归深度是n，每层都会在内存里存一个函数栈帧
    return n * factorial(n-1)
```
解释：递归会一层层压入栈中，最多压n层，所以额外栈空间是O(n)。
### 3. O (n²) 平方空间
特点：额外开辟了n×n的二维空间，比如 n 行 n 列的矩阵。
```python

def create_matrix(n):
    matrix = []
    for i in range(n):
        row = [0] * n  # 每行有n个元素
        matrix.append(row)
    return matrix
```
解释：总共有n×n个元素的额外空间，所以是O(n²)。
### 3.快速计算小步骤
```
1.找循环 / 递归：复杂度基本都来自循环和递归，先定位最内层代码
2.算次数和 n 的关系：看最内层代码执行多少次，和 n 是什么函数关系
3.去系数、留最高阶：得到最终的大 O 结果
```

### 4.常见误区
```
1.不是循环越多复杂度越高：两个并列的单层循环，还是O(n)，不是O(n²)
2.不是复杂度高就一定慢：n 很小时，O(n²)可能比O(n)还快（常数小）；但 n 很大时，低复杂度一定碾压
3.递归空间复杂度不是都为O(n)：要看递归深度，比如二分查找的递归写法深度是logn，空间就是O(logn)
```

### 5. remark

1. return —— 结束整个函数
作用范围：整个函数
效果：一旦执行 return，直接跳出当前整个函数，函数后面的所有代码都不会再运行，同时可以把一个值传回给调用函数的地方。
可以带返回值：后面可以跟数字、变量、列表等，作为函数的输出结果。
```python
def test():
    print("第一行")
    return 100  # 函数到这里直接结束
    print("这行永远不会执行")

result = test()
print(result)  # 输出 100
```
在这道题里，return l 就是：函数执行到这里结束，把最终的有效长度 l 作为结果返回。

2. break —— 结束当前这一层循环
作用范围：离它最近的那一层循环（while / for）
效果：立刻跳出当前这层循环，但是循环外面的代码还会继续执行。
不带返回值：只是跳出循环，不返回任何东西。
```python
运行
for i in range(5):
    if i == 3:
        break  # 遇到3就跳出整个循环
    print(i)
print("循环结束了")
```
输出：
plaintext
0
1
2
循环结束了
到 i=3 时循环直接终止，4 不会打印，但循环外面的文字还是会输出。

3. continue —— 跳过本次循环，进入下一轮
作用范围：离它最近的那一层循环
效果：不跳出整个循环，只是跳过本次循环剩下的代码，直接开始下一轮循环。
```python
运行
for i in range(5):
    if i == 3:
        continue  # 遇到3就跳过本次，继续下一轮
    print(i)
print("循环结束了")
```
输出：
plaintext
0
1
2
4
循环结束了
i=3 时跳过了 print(i)，直接去跑 i=4 了。

4. 补充：pass —— 占位符，什么都不做
它没有任何跳转效果，就是个空语句。当语法要求必须写点什么，但你又不想执行任何操作的时候用它。
```python
if i == 3:
    pass  # 暂时没想好这里写什么，先占个位置保证不报错
```
一句话总结区别
return：直接辞职，整个工作（函数）彻底结束
break：今天下班，当前循环结束，循环外的工作还继续
continue：这页跳过，本轮不做了，直接开始下一轮
