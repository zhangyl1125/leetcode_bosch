# 二、数组

## 题目 

```
在一个城市区域内，被划分成了n * m个连续的区块，每个区块都拥有不同的权值，代表着其土地价值。目前，有两家开发公司，A 公司和 B 公司，希望购买这个城市区域的土地。
现在，需要将这个城市区域的所有区块分配给 A 公司和 B 公司。
然而，由于城市规划的限制，只允许将区域按横向或纵向划分成两个子区域，而且每个子区域都必须包含一个或多个区块。
为了确保公平竞争，你需要找到一种分配方式，使得 A 公司和 B 公司各自的子区域内的**土地总价值之差最小**。

注意：区块不可再分。
```
【输入描述】

第一行输入两个正整数，代表 n 和 m。

接下来的 n 行，每行输出 m 个正整数。

输出描述

请输出一个整数，代表两个子区域内土地总价值之间的最小差距。

【输入示例】

3 3
1 2 3
2 1 3
1 2 3
【输出示例】

0

【提示信息】

如果将区域按照如下方式划分：

1 2 | 3
2 1 | 3
1 2 | 3
两个子区域内土地总价值之间的最小差距可以达到 0。

【数据范围】：

1 <= n, m <= 100；
n 和 m 不同时为 1。

## 整体思路
```
核心思路非常直白：

1. 先算出整个矩阵的总和
2. 提前算好每行的和、每列的和（预处理提速）
3. 把所有横切的位置都试一遍，算差值找最小
4. 把所有竖切的位置都试一遍，算差值找最小
5. 两个最小值再取最小，就是最终答案
```

### 1.前缀和
代码如下：
```python
def main():
    # 1. 读取输入 + 构建矩阵 + 计算总和
    import sys
    input = sys.stdin.read  # 一次性读入所有输入，切成字符串列表，用 `idx` 指针按顺序读取数据，避免逐行读取的性能损耗。
    data = input().split()

    idx = 0
    n = int(data[idx])  # `n`（矩阵行数）
    idx += 1
    m = int(data[idx])  # `m`（矩阵列数）
    idx += 1
    sum = 0
    vec = []
    for i in range(n):
        row = []
        for j in range(m):
            num = int(data[idx])
            idx += 1
            row.append(num)
            sum += num
        vec.append(row)

    # 2. 预处理：计算每行的和、每列的和
    # 统计横向--->① 横向：每行的元素总和
    horizontal = [0] * n    # `horizontal` 是长度为 `n` 的列表，`horizontal[i]` 代表**第 i 行所有元素的总和**
    for i in range(n):
        for j in range(m):
            horizontal[i] += vec[i][j]

    # 统计纵向--->② 纵向：每列的元素总和
    vertical = [0] * m      # `vertical` 是长度为 `m` 的列表，`vertical[j]` 代表**第 j 列所有元素的总和**。
    for j in range(m):
        for i in range(n):
            vertical[j] += vec[i][j]

    # 3. 核心：遍历所有横切位置，找最小差值
    result = float('inf')   # 最终答案，初始设为无穷大，方便后续更新最小值
    horizontalCut = 0       # 横切时，上半部分的总和
    for i in range(n):
        horizontalCut += horizontal[i]      # 把第i行的和加进上半部分
        # 计算两部分的差值，更新全局最小值
        result = min(result, abs(sum - 2 * horizontalCut))

    ```
        上半部分和 = `horizontalCut`
        下半部分和 = 总和 - 上半部分和 = `sum_total - horizontalCut`
        两部分的差值 = | 上半 - 下半 | = `|horizontalCut - (sum_total - horizontalCut)|`
        化简后就是：`abs(2 * horizontalCut - sum_total)`，和代码里的 `abs(sum_total - 2 * horizontalCut)` 完全等价（绝对值不影响正负）。
    ```
    verticalCut = 0
    for j in range(m):
        verticalCut += vertical[j]
        result = min(result, abs(sum - 2 * verticalCut))

    print(result)

if __name__ == "__main__":
    main()
```
时间复杂度： O(n^2)

优化暴力求解，就不用前缀和了，在行向遍历的时候，遇到行末尾就统一一下， 在列向遍历的时候，遇到列末尾就统计一下。

时间复杂度也是 O(n^2)
### 2.优化暴力

代码如下：

```python
def main():
    import sys
    input = sys.stdin.read
    data = input().split()
    
    idx = 0
    n = int(data[idx])
    idx += 1
    m = int(data[idx])
    idx += 1
    sum = 0
    vec = []
    for i in range(n):
        row = []
        for j in range(m):
            num = int(data[idx])
            idx += 1
            row.append(num)
            sum += num
        vec.append(row)

    result = float('inf')
    
    count = 0
    # 行切分
    for i in range(n):
        
        for j in range(m):
            count += vec[i][j]
            # 遍历到行末尾时候开始统计
            if j == m - 1:
                result = min(result, abs(sum - 2 * count))

    count = 0
    # 列切分
    for j in range(m):
        
        for i in range(n):
            count += vec[i][j]
            # 遍历到列末尾时候开始统计
            if i == n - 1:
                result = min(result, abs(sum - 2 * count))

    print(result)

if __name__ == "__main__":
    main()
```

## 3. 完整举例

输入内容：
```
2 3
1 2 3
4 5 6
```

也就是 `n=2` 行，`m=3` 列，矩阵内容：

```
行0: 1  2  3
行1: 4  5  6
```

### 步骤 1：读入数据，计算总和

- 总和 `sum_total = 1+2+3+4+5+6 = 21`
- 二维矩阵 `vec = [[1,2,3], [4,5,6]]`

### 步骤 2：计算行和、列和

- 行和 `horizontal`：
  - 第 0 行：1+2+3 = 6
  - 第 1 行：4+5+6 = 15
  - 结果：`horizontal = [6, 15]`
- 列和 `vertical`：
  - 第 0 列：1+4 = 5
  - 第 1 列：2+5 = 7
  - 第 2 列：3+6 = 9
  - 结果：`vertical = [5, 7, 9]`

### 步骤 3：遍历所有横切方案

初始 `result=无穷大`，`horizontalCut=0`

- **i=0**（切在第 0 行下面，上下各 1 行）：`horizontalCut += 6 → 6`
差值 = `|21 - 2×6| = |21-12| = 9``result = min(无穷大, 9) = 9`
- **i=1**（切在第 1 行下面，下半部分为空）：`horizontalCut +=15 → 21`
差值 = `|21 - 42| = 21``result = min(9, 21) = 9`

横切的最小差值是 9。

### 步骤 4：遍历所有竖切方案

初始 `verticalCut=0`

- **j=0**（切在第 0 列右边，左 1 列、右 2 列）：`verticalCut +=5 →5`
差值 = `|21 - 10| =11``result = min(9, 11) =9`
- **j=1**（切在第 1 列右边，左 2 列、右 1 列）：`verticalCut +=7 →12`
差值 = `|21 - 24| =3``result = min(9, 3) =3`
- **j=2**（切在第 2 列右边，右半部分为空）：`verticalCut +=9 →21`
差值 = `|21 -42|=21``result = min(3,21)=3`

### 最终结果

输出 `3`。
对应的最优切法：竖着切在第 1 列和第 2 列之间，左边两列和为 12，右边一列和为 9，差值是 3，是所有切法里最小的。
